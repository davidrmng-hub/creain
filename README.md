# CreaIN — Website

Sitio web de CreaIN, agencia creativa: creatividad humana, potenciada por IA.

- Sitio estático (HTML, CSS y JS), sin paso de compilación.
- Publicado en Netlify (`netlify.toml` publica la raíz).
- Formulario de contacto con Netlify Forms.
- Calendario de asesorías con Cal.com (`CAL_LINK` en `main.js`).
- Bilingüe ES/EN (textos en inglés en `main.js`).
